# KTX 공개 시간표 조회 관련 고지

> 2026-08-12에 확인한 공개 자료를 바탕으로 한 일반적인 위험 안내이며 법률자문이나 한국철도공사의 유권해석이 아니다.

## 이 스킬의 경계

`ktx-booking`은 한국철도공사가 일반 공개한 운행시간표 게시판과 XLSX 첨부만 한 번 읽는다.

- 회원 로그인과 credential을 사용하지 않는다.
- Korail 앱 내부 API 또는 `korail2`를 사용하지 않는다.
- Dynapath token, CAPTCHA 또는 anti-bot 장치를 재현·우회하지 않는다.
- 실시간 좌석 상태를 조회하지 않는다.
- 예약·예약대기·결제·취소·반복 감시를 실행하지 않는다.

이 구조는 계정 기반 자동예매보다 위험을 크게 줄이지만, 운영사의 최신 이용조건을 면제하는 것은 아니다. 공식 사이트가 접근을 제한하거나 자동화 중단을 요구하면 즉시 중단해야 한다.

## 공식 근거

[한국철도공사 회원가입 및 이용에 관한 약관](https://mdev.letskorail.com/ebizmk/common/mk_join_agree.do?reqDvFlg=1) 제11조는 매크로 등 자동화 프로그램이나 부정한 수단을 이용한 **예매**, 다량 예매·취소, 웃돈 거래 등을 회원 자격상실 또는 서비스 이용제한 사유로 규정한다.

이 스킬은 해당 위험을 피하기 위해 예매 기능과 계정 접근을 제공하지 않는다. 결과는 공개 운행계획일 뿐 좌석 구매 가능성을 의미하지 않는다.

## 사용 규칙

- 한 사용자 요청에 한 번만 조회하고 polling·병렬 수집·대량 크롤링을 하지 않는다.
- 공개 시간표 파일과 게시판 외의 비공개 endpoint를 사용하지 않는다.
- 결과에는 원본 파일 기준일과 공식 URL을 함께 표시한다.
- 구매가 필요하면 공식 코레일 예매 페이지를 사용자가 직접 이용한다.
