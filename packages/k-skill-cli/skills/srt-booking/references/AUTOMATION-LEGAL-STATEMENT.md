# SRT 공개 시간표 조회 관련 고지

> 2026-08-12에 확인한 공개 자료를 바탕으로 한 일반적인 위험 안내이며 법률자문이나 주식회사 에스알의 유권해석이 아니다.

## 이 스킬의 경계

`srt-booking`은 주식회사 에스알이 일반 공개한 운행시각표 페이지와 HWP 첨부만 한 번 읽는다.

- 회원 로그인과 credential을 사용하지 않는다.
- `SRTrain`, SRT 앱 내부 API 또는 좌석선택 endpoint를 사용하지 않는다.
- CAPTCHA 또는 anti-bot 장치를 재현·우회하지 않는다.
- 실시간 좌석 상태를 조회하지 않는다.
- 예약·예약대기·결제·취소·반복 감시를 실행하지 않는다.

공식 HWP와 임시 Markdown은 helper 종료 시 삭제된다. 이 구조는 계정 기반 자동예매보다 위험을 크게 줄이지만, 운영사의 최신 이용조건을 면제하는 것은 아니다.

## 공식 근거

[에스알의 매크로 프로그램을 이용한 승차권 예매 금지 안내](https://etk.srail.kr/cms/article/view.do?pageId=TK0502000000&postNo=793)는 매크로를 이용한 **승차권 예매**가 시스템 과부하와 다른 고객의 예매 기회 방해를 초래할 수 있고 적발 시 회원 탈퇴 처리될 수 있다고 안내한다.

[에스알 회원가입 및 이용에 관한 약관](https://etk.srail.kr/cms/archive.do?pageId=TK0503010000) 제10조는 다량 예약 후 임박 취소, 타인 계정 도용과 건전한 서비스 이용 저해를 탈퇴 사유로 규정한다.

이 스킬은 해당 위험을 피하기 위해 예매 기능과 계정 접근을 제공하지 않는다. 결과는 공개 운행계획일 뿐 좌석 구매 가능성을 의미하지 않는다.

## 사용 규칙

- 한 사용자 요청에 한 번만 조회하고 polling·병렬 수집·대량 크롤링을 하지 않는다.
- 공개 운행시각표 페이지와 첨부 외의 비공개 endpoint를 사용하지 않는다.
- 결과에는 원본 파일 기준일과 공식 URL을 함께 표시한다.
- 접근 제한이나 비정상 접근 경고가 나타나면 즉시 중단한다.
- 구매가 필요하면 공식 SRT 예매 페이지를 사용자가 직접 이용한다.
