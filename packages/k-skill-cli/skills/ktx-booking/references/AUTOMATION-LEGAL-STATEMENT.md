# KTX 공식 시간표 조회 관련 고지

이 스킬은 한국철도공사가 공개한 시간표 게시판과 XLSX 첨부파일만 읽는다.

- 회원 로그인과 credential을 사용하지 않는다.
- Korail 앱 내부 API, `ScheduleView`, Dynapath token을 호출·생성·재현하지 않는다.
- CAPTCHA, anti-bot 또는 접근통제를 우회하지 않는다.
- 실시간 잔여석, 예약, 좌석 선점, 결제, 취소를 실행하지 않는다.

결과는 공개 운행계획 시간표이며 실제 운휴·지연·잔여석 정보가 아니다. 실제 이용 전에는 공식 코레일 예매 페이지에서 다시 확인해야 한다.
